# Visuels des prestations et IPTV

Créations originales avec l’outil intégré imagegen, sans téléchargement depuis un site tiers. Format final : WebP 1200 × 750, adapté aux cartes 8:5. Les PNG originaux sont conservés dans le dossier generated_images de Codex.

Fichiers : `public/services/paysage/{shooting-photo,creation-site-web,logiciels-informatiques,iptv}.webp`. Le script `scripts/prepare-quote-images.mjs` réalise uniquement leur redimensionnement et leur encodage. Les images sont affectées aux produits depuis l’administration après publication des fichiers.
